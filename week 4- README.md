# Week 4 – Alert Threshold Configuration & Live Tail Dashboard

## 📌 Project Overview

This project is the **Week 4 frontend implementation** of an Analytics Dashboard.

The main objective is to build:

1. An **Alert Threshold Configuration UI**
2. A **Terminal-style Live Tail component** with auto-scrolling logs

The project is built using **HTML, CSS, and JavaScript** and works completely on the frontend without requiring a backend.

---

## 🚀 Features

### Alert Threshold Configuration

* Configure alerts for different services
* Select log levels
* Set alert thresholds
* Configure time windows
* Enable or disable alerts
* Save alert configurations
* Reset configuration
* Display configured alerts in the dashboard

### Live Tail

* Terminal-style log viewer
* Simulated real-time log streaming
* Automatic scrolling to the latest logs
* Pause and resume live updates
* Clear log output
* Search/filter logs
* Export logs
* Different log levels such as INFO, WARN, ERROR, and DEBUG
* Timestamp display for each log

## ▶️ How to Run the Project

### Method 1 – VS Code

1. Download or clone this repository.
2. Open the project folder in **Visual Studio Code**.
3. Make sure all four files are in the same folder.
4. Open `index.html`.
5. Right-click on `index.html`.
6. Select **Open with Live Server**.

The dashboard will open in your browser.

### Method 2 – Directly in Browser

You can also open `index.html` directly in a web browser.

## 💻 Frontend Architecture

The application is divided into three main frontend files:

### `index.html`

Contains the structure and layout of the dashboard, including the alert configuration section and Live Tail terminal.

### `style.css`

Contains the complete styling, responsive layout, dashboard panels, buttons, forms, terminal interface, and visual components.

### `script.js`

Handles the frontend functionality, including alert configuration, live log generation, filtering, auto-scrolling, pause/resume, clearing logs, and exporting logs.
