# LogStream Analytics Dashboard - Week 3 REA

## Week 3 Task

Build the ECharts histogram components showing log volume over time alongside Namratha and style the dashboard panels.

## Frontend Implementation

This project contains the frontend implementation of the LogStream Analytics Dashboard.

### Features

- ECharts log volume histogram
- Log volume over time
- Time range selection
- Log level distribution chart
- Service-wise log volume chart
- Summary statistic cards
- Recent logs table
- Dashboard panel styling
- Responsive layout
- Refresh functionality
- Responsive ECharts resizing

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Apache ECharts
