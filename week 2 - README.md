# LogStream Week 2 - Search Results Frontend

## Project

LogStream is a distributed log analytics and alerting platform.

This repository contains the frontend implementation for Week 2 of the Analytics Dashboard.

## Developer

Shaik Khaja Moinuddin

## Week 2 Responsibility

Build the search-results rendering and pagination component, wired to the query interface.

## Features

- Search logs by message or service
- Filter by service name
- Filter by log level
- Search results table
- Timestamp rendering
- Log-level badges
- Response-time indicators
- Pagination
- Previous / Next navigation
- Page number navigation
- Rows per page selection
- Loading state
- Empty-results state
- Error state
- Retry functionality
- Clear search functionality
- Responsive frontend
- Search API integration structure

## Technologies

- HTML5
- CSS3
- JavaScript
- Fetch API
